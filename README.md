# NeuroAgro AI 🌱

AI-powered agriculture system using Flask + Machine Learning.

## Features
- Crop Recommendation
- Irrigation Prediction
- Disease Detection (CNN)
- Yield Prediction

## Tech Stack
- Python (Flask)
- Scikit-learn
- TensorFlow
- HTML/CSS/JavaScript

## How to Run
pip install -r requirements.txt  
python app.py
